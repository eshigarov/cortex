# Онтология Cortex

Каркас канонического слоя: сущности, связи, правила. Не привязан к продукту — это модель предметной области.

## Файлы

- `core.ttl` — 12 классов и 16 связей на пространстве имён `https://cortex.example/ns/core#`.
- `taxonomy.skos.ttl` — SKOS-таксономии: отрасли, типы сценариев, типы объектов.
- `shapes.shacl.ttl` — SHACL-правила: обязательные поля и кардинальности.
- `demo.ttl` — пример данных: ГОК, дробилка, простой, показатель, решение.
- `validate.py` — проверка: парсинг, SHACL, негативный тест.

## Запуск проверки

```bash
/home/shigarov/.venvs/ontology/bin/python ontology/validate.py
```

Ожидаемый вывод: `SHACL: соответствует` и `негативный тест: поймали`.

## Принципы

1. **schema.org — не ядро.** Это словарь для внешней разметки, в нём нет времени и n-арных связей. Маппинг наружу — отдельным файлом.
2. **SKOS — для таксономий, OWL — для классов и связей, SHACL — для контроля данных.**
3. Имена классов и свойств — по-английски, метки — по-русски (`rdfs:label@ru`).
4. Маппинги на внешние справочники (ОКВЭД2, ОКПД2, ОКОФ, ECLASS) — отдельный слой, ядро не правится.

## Что дальше

- `mappings/schema.org.jsonld` — контекст для JSON-LD на сайте.
- `mappings/okpd2.ttl` — пилотный маппинг одной товарной группы на ECLASS по IRDI.

## Neo4j (операционный слой)

Импорт онтологии в Neo4j через n10s — одной командой:

    bash ontology/neo4j-import.sh

Скрипт идемпотентен: создаёт constraint `n10s_unique_uri`, инициализирует graph config, добавляет префикс `core`, затем грузит `core.ttl`, `taxonomy.skos.ttl` и `demo.ttl`.

Пароль берётся из `NEO4J_PASS` или из файла `~/.cache/neo4j/.pw` (права 600). В репозиторий секреты не попадают.

Проверка на стенде 04.11.2026: 158 + 45 + 33 триплета, статус OK, 57 узлов `:Resource`.

Грабли, заложенные в скрипт: без constraint импорт падает; `DETACH DELETE` сносит graph config; префикс нужно задавать до первого импорта.

## GraphRAG-демо

    /home/shigarov/.venvs/ontology/bin/python ontology/graphrag-demo.py

Считает эмбеддинги имён узлов через локальный `nomic-embed-text`, создаёт векторный индекс `node_embeddings` (768, cosine) и показывает связку «векторный поиск → обход связей».

Проверка 04.11.2026: запрос «оборудование остановилось, простой несколько часов» → ближайший узел «Заменить броню конуса» (0.873), от него 2 хопа до «Дробилки КМД-2200», «Простоев, ч/мес» и «Регламента ТО».

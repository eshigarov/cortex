# Онтология Cortex

Каркас канонического слоя: сущности, связи, правила. Не привязан к продукту — это модель предметной области.

## Файлы

- `core.ttl` — 12 классов и 16 связей на пространстве имён `https://cortex.example/ns/core#`.
- `taxonomy.skos.ttl` — SKOS-таксономии: отрасли, типы сценариев, типы объектов.
- `shapes.shacl.ttl` — SHACL-правила: обязательные поля и кардинальности.
- `demo.ttl` — пример данных: ГОК, дробилка, простой, показатель, решение.
- `validate.py` — проверка: парсинг, SHACL, негативный тест.

## Запуск проверки

```bash
/home/shigarov/.venvs/ontology/bin/python ontology/validate.py
```

Ожидаемый вывод: `SHACL: соответствует` и `негативный тест: поймали`.

## Принципы

1. **schema.org — не ядро.** Это словарь для внешней разметки, в нём нет времени и n-арных связей. Маппинг наружу — отдельным файлом.
2. **SKOS — для таксономий, OWL — для классов и связей, SHACL — для контроля данных.**
3. Имена классов и свойств — по-английски, метки — по-русски (`rdfs:label@ru`).
4. Маппинги на внешние справочники (ОКВЭД2, ОКПД2, ОКОФ, ECLASS) — отдельный слой, ядро не правится.
